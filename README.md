# MEMORY FORGE — 54-Card PAO Memory Training App

A specialized, cognitive-science-driven web application to memorize and master a custom 54-card Person-Action-Object (PAO) memory system.

Live on GitHub Pages: [https://topro19.github.io/memory-forge/](https://topro19.github.io/memory-forge/)

## The 54-Card PAO Associations
- **Hearts ♥**: Naruto Universe (Tsunade, Naruto, Madara, Rei, Lee, Jinchūriki, Kurama, Fugaku, Pain, Sasuke, Kakashi, Hinata, Jiraiya)
- **Spades ♠**: One Piece Universe (Law, Nami, Luffy, Zoro, Laboon, Jinbe, Kaido, Franky, Perona, Sanji, Joyboy, Boa Hancock, Buggy)
- **Diamonds ♦**: Pokémon Universe (Tyranitar, Nidoking, Mewtwo, Rayquaza, Lucario, Jigglypuff, Kyogre, Flareon, Pikachu, Snorlax, Arceus, Gardevoir, Ditto)
- **Clubs ♣**: The Amazing World of Gumball (Tobias, Nicole, Masami, Rachel, Leslie, Julius, Carrie, Fuzzy, Penny, Sarah, Principal Brown, Anais, Richard)
- **Jokers ★**: Saitama (Red Joker) & Boo Boo the Fool (Black Joker)

## Core Capabilities
- **8 Training Modes**: Person Recall, Action Recall, Object Recall, Full Triad Recall, Reverse Lookup, Shuffled Deck Exam, Speed Challenge, Suit Drills.
- **Three-Card PAO Image Challenge**: Combine 3 cards into a dynamic mental image (Person 1 + Action 2 + Object 3).
- **Spaced Repetition System (SRS)**: Independent SM-2 interval tracking for Person, Action, and Object components.
- **Mistake & Interference Audit**: Confused characters, actions, objects, error logs, and one-click mistake drilling.
- **Analytics & Calendar Heatmap**: Retention rate, latency speed, suit-wise accuracy, and 60-day visual activity heatmap.
- **100% Offline & Private**: Zero cloud dependency; all progress stored in browser storage.
